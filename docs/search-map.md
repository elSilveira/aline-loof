# Regras gerais

Cada página deve ter um objetivo principal.

Antes de criar ou modificar uma página, verificar:

1. qual é a intenção de busca;
2. qual é a palavra-chave principal;
3. quais assuntos relacionados devem aparecer;
4. quais perguntas o usuário pode ter;
5. qual ação queremos que ele realize;
6. se já existe outra página atendendo à mesma intenção.

Evitar criar páginas diferentes que respondem exatamente à mesma busca.

Exemplo a evitar:

/consultoria-imagem
/consultoria-de-imagem
/consultora-de-imagem

Se todas tiverem o mesmo objetivo, deve existir apenas uma página principal.
